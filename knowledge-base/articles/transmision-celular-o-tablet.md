Si vas a usar tu celular o tablet para transmitir tu celebración, sigue estos consejos para asegurar una buena experiencia:
✅ Antes de comenzar:
- Usa un celular con buena calidad de video y audio.
- Activa el modo “No molestar” para evitar llamadas o notificaciones durante la transmisión.
- Haz una prueba de conexión:
- En interiores, el WiFi suele funcionar mejor.
- En exteriores, el 4G/5G podría ser más estable.
- Quien esté a cargo de la transmisión debe evitar hablar, gritar o aplaudir, para no interrumpirla.
- Usa un trípode para mayor estabilidad.
- Revisa el espacio de almacenamiento del dispositivo. El video se guarda automáticamente si hay espacio disponible (hasta 6 GB por hora).

Si no hay espacio, la transmisión se hará igual, pero no se guardará el archivo localmente.

📥 Descarga el app para transmitir
Para transmitir, debes instalar la aplicación Event Live desde los siguientes enlaces:
- [Google Play](https://play.google.com/store/apps/details?id=pro.eventlive&hl=en_US&pcampaignid=pcampaignidMKT-Other-global-all-co-prtnr-py-PartBadge-Mar2515-1https://play.google.com/store/apps/details?id=pro.eventlive&hl=en_US&pcampaignid=pcampaignidMKT-Other-global-all-co-prtnr-py-PartBadge-Mar2515-1)
- [Apple Store](https://apps.apple.com/us/app/eventlive-live-stream-event/id1457137042)
Una vez descargada, solo haz clic en el enlace oficial del evento que se activará en la web del evento, ¡y listo! Podrás comenzar a transmitir.

🧪 Haz una prueba antes del gran día
Te recomendamos realizar la prueba por lo menos 1 día antes, idealmente desde el mismo lugar donde se hará el evento.
Así podrás:
- Verificar la conexión a internet
- Familiarizarte con la aplicación
- Probar cámara, sonido y ángulos
